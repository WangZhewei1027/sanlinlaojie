# 场景编排：Three.js Editor + 共享变换时间轴

2026-10-22：场景编辑器恢复 Light 主题，保留现有紧凑工作台布局、应用属性/时间轴和统一撤销交互。Three.js Editor r183 的原生视口、团队素材库、上传、二维码和保存流程继续使用。本页为 Operate 模式的局部扩展；全站视觉规范仍以 `docs/design-system.md` 和现有 token 为准。

- `SceneEditor` 在同一个 DOM 中组合标题/保存栏、左侧视口工具与素材/对象设置、中间原生视口和底部变换时间轴。场景对象选择器与视口选择共用实例 ID，GLB 子网格映射回实例根节点。
- 工作台固定使用 Light 主题：`app/globals.css` 的 `:root` 与 `.scene-workspace-theme` 共用全站浅色语义 token，局部样式保留 6px 圆角，并加深辅助文字与错误色，保证选中浅灰背景和浅底上的可读性。全站字体与状态语义保持一致，Three 原生视口使用上游 light 背景与网格。表面靠色阶和边线分区；按钮、输入和选中状态复用后台组件。时间轴的 12px 文字用于通道、刻度和数值，说明文字沿用 14px 辅助字号。
- 桌面侧栏宽 16.5rem；小于 1024px 默认收起，展开时覆盖视口。底部时间轴在窄屏保留，内容区独立滚动；小于 640px 时高 36vh，工具栏横向滚动。收起侧栏和切换预览保留编辑会话。
- 时间轴展示所选实例的 position/rotation/scale 共 9 个通道。位置标米、旋转标度、时间标秒；保存和采样使用 Euler XYZ 弧度，保留多圈旋转。数字提交更新静态值，已有轨道则在当前时间写入关键帧。
- 未选择对象时，空状态提示固定居中于标尺下方的可视区域，不随轨道网格滚动或缩放偏移；桌面和窄屏均保持完整可读。标尺、播放与时长控制继续显示，轨道区的播放线、结束线及结束区域遮罩不渲染。重新选择模型后恢复 9 个通道及对应轨道标记；窄屏空状态示例见 `SceneTimeline` 的 `EmptyNarrow` story。
- 时间轴仿 Logic 走带：标尺上方标签、下方刻度，刻度与吸附网格随缩放自适应；深色播放头使用 `primary` 语义色并带五边形把手，点击/拖动标尺定位。标尺上的结束旗标即场景时长，拖动调整（吸附网格，按住 Alt/Option 精确到毫秒），结束点之后的区域叠加浅灰遮罩，超出时长的关键帧半透明保留；拖到右缘自动扩展可视范围。循环开启时标尺顶部显示循环带。Ctrl/⌘ + 滚轮或捏合缩放，工具栏提供缩小、放大、适应全部；播放时视图随播放头翻页。通道列横向吸附，标尺纵向吸附。
- 菱形按钮添加/移除当前关键帧，双击轨道添加，拖动关键帧调整时间（同样吸附网格），Delete/Backspace 删除选中帧。插值提供线性、缓动、保持；导入后的自定义 Bezier 显示为“原有曲线”，修改数值或时间不会自动改写曲线。
- 文档只有一份撤销历史，最多保留 60 个过去快照；原生变换拖动结束提交一次。标题、素材、片段设置和关键帧共用历史。Ctrl/⌘ S 保存，Ctrl/⌘ Z 撤销、Shift Z 重做，空格播放/暂停；W/E/R 切换原生变换，F 聚焦。
- 播放与只读状态禁用变换和关键帧编辑；预览隐藏侧栏、时间轴及编辑辅助器，保留播放、时间和返回编排。加载、错误、权限提示继续使用同一主题。
- 二维码浮层挂到标题栏容器并继承 Light 主题，向内避让边缘；视口点击、Escape 或卸载时关闭。
- 每个编辑器持有独立可销毁的 Scene Core，会话、订阅、RAF 与原生视口随 React 卸载释放。模型模板按 URL 在当前视口引用计数，独立克隆；引用归零及迟到加载都会释放资源。GLB 内置动画继续由 Three.AnimationMixer 求值。
- 保存为文档 schema 6，编译播放 schema 4。只开放共享协议可保存、两端可播放的实例变换和 GLB 片段；原生 Editor 的独立 JSON、任意几何/材质/灯光/脚本及层级重排没有编辑入口。

原生视口来源、MIT 许可、哈希和补丁见 `vendor/three-editor/README.md`；协议、迁移与自动验收见 `docs/scene-asset.md`。已对照 `SceneEditor`、`SceneTimeline`、`useSceneDocument`、局部 CSS 及 `.impeccable/review/desktop.png`、`mobile.png`、`scene-light-qr.png` 核实本轮主题说明，沿用现有视觉系统。
