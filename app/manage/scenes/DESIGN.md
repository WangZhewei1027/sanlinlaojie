# 场景编排：Three.js Editor + 共享变换时间轴

2026-10-22：时间轴改为 Logic 式多轨编排：每个对象一条轨道，分组和层级直接在轨道头部编辑，变换关键帧默认收起、展开轨道后才出现；侧栏不再有对象选择器或层级树。同日场景编辑器恢复 Light 主题，保留现有紧凑工作台布局、应用属性/时间轴和统一撤销交互。Three.js Editor r183 的原生视口、团队素材库、上传、二维码和保存流程继续使用。本页为 Operate 模式的局部扩展；全站视觉规范仍以 `docs/design-system.md` 和现有 token 为准。

- `SceneEditor` 在同一个 DOM 中组合标题/保存栏、左侧视口工具、素材库与所选轨道检视器、中间原生视口和底部时间轴。时间轴轨道与视口选择共用节点 ID（实例或分组），GLB 子网格映射回实例根节点；侧栏只检视当前选择，不列出对象。
- 工作台固定使用 Light 主题：`app/globals.css` 的 `:root` 与 `.scene-workspace-theme` 共用全站浅色语义 token，局部样式保留 6px 圆角，并加深辅助文字与错误色，保证选中浅灰背景和浅底上的可读性。全站字体与状态语义保持一致，Three 原生视口使用上游 light 背景与网格。表面靠色阶和边线分区；按钮、输入和选中状态复用后台组件。时间轴的 12px 文字用于通道、刻度和数值，说明文字沿用 14px 辅助字号。
- 桌面侧栏宽 16.5rem；小于 1024px 默认收起，展开时覆盖视口。底部时间轴在窄屏保留，内容区独立滚动；小于 640px 时高 36vh，工具栏横向滚动。收起侧栏和切换预览保留编辑会话。
- 时间轴仿 Logic 编排区：每个模型实例一条轨道，分组是 Track Stack 式的父轨道，头部带展开三角和成员数；轨道顺序就是 `instances` 顺序，分组成员保持连续。头部点击选择，⌘/Ctrl 点击加选，Shift 点击连选；双击名称或按 Enter 改名（实例清空名称则回到素材名）；拖动头部排序，拖到分组头部中段放入分组，上下边缘插到前后；⌘G 把所选轨道包进新分组，⇧⌘G 或检视器“取消编组”把成员上移一层。分组和移动都保持成员的静态世界姿态（已有关键帧的通道仍按新父节点的局部值播放），最多 16 个分组、嵌套 4 层；成员清空的分组自动移除，删除分组会连同成员一起删除。
- 轨道主行显示 region：GLB 片段从起始时间画到片段结束，循环片段延伸到场景结束并标出每次重复，拖动 region 修改起始时间（吸附网格，Alt/Option 精确到毫秒）。收起时主行底部用淡色刻度提示有关键帧的时间点，只能看不能编辑。点轨道右侧曲线按钮或按 A 展开参数 lane：位置/旋转/缩放三条，每条合并 X/Y/Z 关键帧，并带三个数值框和关键帧菱形；只有部分轴有帧时菱形为空心。拖动合并帧会同时移动三个轴，再展开可单独编辑 X/Y/Z。位置标米、旋转标度、时间标秒；保存和采样使用 Euler XYZ 弧度，保留多圈旋转。数字提交更新静态值，已有轨道则在当前时间写入关键帧。分组轨道同样可以展开参数 lane，为整组做动画。
- 头部列宽 300px，参数 lane 用浅灰底色表示从属于上方轨道。时间轴顶部边缘可拖动调高（140px 至 70% 视口高度，方向键微调），高度记在本机浏览器。
- 场景没有对象时，空状态提示固定居中于标尺下方的可视区域，不随轨道网格滚动或缩放偏移；标尺、播放与时长控制继续显示，轨道区的播放线、结束线及结束区域遮罩不渲染。
- 时间轴仿 Logic 走带：标尺上方标签、下方刻度，刻度与吸附网格随缩放自适应；深色播放头使用 `primary` 语义色并带五边形把手，点击/拖动标尺定位。标尺上的结束旗标即场景时长，拖动调整（吸附网格，按住 Alt/Option 精确到毫秒），结束点之后的区域叠加浅灰遮罩，超出时长的关键帧半透明保留；拖到右缘自动扩展可视范围。循环开启时标尺顶部显示循环带。Ctrl/⌘ + 滚轮或捏合缩放，工具栏提供缩小、放大、适应全部；播放时视图随播放头翻页。通道列横向吸附，标尺纵向吸附。
- 菱形按钮添加/移除当前关键帧，双击参数 lane 添加，拖动关键帧调整时间（同样吸附网格），Delete/Backspace 删除选中帧；焦点在轨道头部时 Delete/Backspace 删除所选轨道。插值提供线性、缓动、保持；导入后的自定义 Bezier 显示为“原有曲线”，修改数值或时间不会自动改写曲线。
- 文档只有一份撤销历史，最多保留 60 个过去快照；原生变换拖动结束提交一次。标题、素材、片段设置和关键帧共用历史。Ctrl/⌘ S 保存，Ctrl/⌘ Z 撤销、Shift Z 重做，空格播放/暂停；W/E/R 切换原生变换，F 聚焦。
- 播放与只读状态禁用变换和关键帧编辑；预览隐藏侧栏、时间轴及编辑辅助器，保留播放、时间和返回编排。加载、错误、权限提示继续使用同一主题。
- 二维码浮层挂到标题栏容器并继承 Light 主题，向内避让边缘；视口点击、Escape 或卸载时关闭。
- 每个编辑器持有独立可销毁的 Scene Core，会话、订阅、RAF 与原生视口随 React 卸载释放。模型模板按 URL 在当前视口引用计数，独立克隆；克隆体包在 `pivot` 节点里，按包围盒把底部中心对齐到实例原点（与小程序单素材 AR 放置相同），所以带偏移原点的导入模型（如 Sketchfab/FBX 导出）也以树根等底部中心为旋转、缩放和落点基准。偏移位于 AnimationMixer 驱动的子树之外；素材预览只按包围盒取景，看不出原点偏移。引用归零及迟到加载都会释放资源。GLB 内置动画继续由 Three.AnimationMixer 求值。
- 保存为文档 schema 6；编译时无分组的场景保持播放 schema 4，有分组的输出 schema 5。只开放共享协议可保存、两端可播放的实例/分组变换和 GLB 片段；原生 Editor 的独立 JSON、大纲树、任意几何/材质/灯光/脚本没有编辑入口。轨道模型（头部 + region lane + 可展开参数 lane）为后续音频、视频等素材轨道预留，新类型只需提供自己的 region 和参数 lane。

原生视口来源、MIT 许可、哈希和补丁见 `vendor/three-editor/README.md`；协议、迁移与自动验收见 `docs/scene-asset.md`。已对照 `SceneEditor`、`SceneTimeline`、`SceneTrack*`、`useSceneTracks`、`useSceneDocument`、局部 CSS 及 `.impeccable/review/desktop.png`、`mobile.png`、`scene-light-qr.png` 核实本轮主题说明，沿用现有视觉系统。
